# 阶段 C：知识回接执行报告

日期：2026-09-09。范围依据用户明确下发 C、11E / ADR-0035；完成本地技术验证，不代表用户正式验收或工业验收。停止在 R1/M9.5 的阶段 C，不进入 M10。

## 实际完成

增加固定 Release 的 Forecast knowledge-context 契约、组合服务与现有运行态页面卡片。用户选择同空间知识版本并输入问题，经既有 Release Query/Gateway 检索后，服务从该 Release 的冻结 Claim/Evidence 恢复支持材料，重查当前权限、密级、Evidence/Anchor 和源有效性。检索摘要、未获有效证据支持的命中及其他 Release 引用不直接返回。引用、原文定位、发布/预测哈希和核验时间可追溯。

卡片与已有 Observed/Forecast/Hypothesis 并列，位于 Wiki/Graph/Ask 等已有运行态视图；引用来源链表示本次检索关系，不冒充正式知识图中的因果边。修改查询条件清除旧结果，过期异步响应不会覆盖新输入。空态、失败重试、弃用版本提示及证据不足说明已实现。

这是最小的可引用知识背景回接：可检索已发布的规程/案例/主张，但不自动判定适用设备、故障根因或措施有效性，也没有新增专业 RCA 推理模型。

## 验证

- Python 157 项通过，5 项 integration 标记未包含在该单元测试命令内；其中 C 新增 5 项权限、跨空间、密级/引用筛选、无依据拒绝和空白问题验证。Ruff、格式与 98 模块类型检查通过。
- 前端共 31 项测试通过；C 新增 3 项显式选择、旧结果清除、异步隔离和空态/失败重试验证。lint、类型、格式与构建通过，最终小修定向复验 3 项通过。
- 真实软件链：明确合成参考资料 → Source/Parse → Schema/Compile → 职责分离 Review → 正式 Claim/accepted Evidence → 质量门禁/发布 → 现有 Chronos-2 制品的固定 Release 回接，取得 1 条有效引用并打开真实原文定位接口。分别查询两个不可变 Release，返回对应的固定引用；旧 Forecast 全文及哈希保持不变。
- 无关问题返回 INSUFFICIENT_EVIDENCE；跨空间返回 404、非成员返回 403。独立合成参考源失效前可引用，失效后不返回支持材料；正常演示参考仍可引用。测试发布流程留下可审计历史，并把演示 stable 指针恢复到正常版本。
- 未新增 Chronos 推理，复用 B 的真实制品。回接调用既有检索 Gateway；合成资料使用本地结构化编译 Provider，不冒充外部 LLM 专家判断。API/前端部署以及真实页面资产检查完成，预测 worker 重启对齐 C 版本。
- 本轮未执行完整浏览器点击或视觉验收；组件测试、部署资产检查、真实 API/原文定位检查分别留证，不相互冒充。
