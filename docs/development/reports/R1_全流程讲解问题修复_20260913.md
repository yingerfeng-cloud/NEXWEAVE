## 修复结果

1. **创建空间误报网络错误**

   原因是 React 异步请求返回后再次读取已失效的 `event.currentTarget`，表单 reset 抛出的 `TypeError` 被页面统一映射为网络错误。现在在第一次事件回调中保存表单引用，并在请求完成后使用该引用；同时新建提交会清空旧错误。变更：`apps/web/src/SpacesPage.tsx`。

2. **已解析资料未出现在编译页**

   原因是资料列表仓储原先为了轻量化固定返回空 `versions`，而编译中心依赖该字段筛选 `PARSED/PARTIAL`。现在列表按租户/空间一次读取版本摘要，并按主体密级过滤；列表路由复用公开字段投影，避免 `object_key` 等内部字段泄露或触发严格契约 500。变更：`apps/api/src/nexweave_api/source_repository.py`、`apps/api/src/nexweave_api/source_routes.py`。

3. **状态类自然问句召回不足**

   原因是 PostgreSQL `plainto_tsquery('simple', ...)` 对整句形成 AND 查询，`What is the state of Pump A?` 要求资料同时包含问句框架词。现在仅对状态/条件类固定问句前缀做确定性聚焦（本例为 `Pump A`），保留原语义向量召回、RRF、固定 Release、权限过滤和引用 Evidence 门禁；审计 `retrieval_config` 同时记录实际全文检索词。变更：`apps/api/src/nexweave_api/release_repository.py`。

4. **Ask 引用缺少原文入口**

   现有安全预览路由已支持版本与 Anchor 参数；Ask 引用卡现在直接生成 root-relative 的原文定位链接。变更：`apps/web/src/M7Knowledge.tsx`、`apps/web/src/styles/core-structure.css`。
