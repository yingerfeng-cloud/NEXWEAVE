## 实际完成

现有运行态页面支持选择已有受控 CSV、已发布时序 Schema/Profile 和知识对象，映射时间/信号/单位/质量列，先预检再保存不可变绑定。保存时后端重新验证，预检不持久化业务对象、不调用模型；编辑使预检失效，保存失败可用原幂等键重试。前端增加历史窗口与未来输入空值限制、同历史窗口双场景末端 P10/P50/P90 比较及条件预测边界说明。

平台新增有界 CSV 预览、绑定预检和最小对象选择投影。修复预测适配器遗漏 R1 独立失效记录的门禁：预览、绑定、执行前和制品发布前检查源失效及归档。真实资料选择同时发现并修复 Source 列表/详情/归档的响应投影错误：内部 archived_at 和嵌套版本 object_key 不再破坏公开契约，不放宽 extra=forbid；数据库归档时间、内部存储引用仍保留。

- 本阶段前端 28 项测试及格式、lint、类型和构建检查通过；交互覆盖预检失效、保存重试与不兼容场景。前端部署到 8080，实际返回资产包含绑定、预检、对象选择和失效提示。没有把组件模拟测试或资产检查称为完整浏览器点击 E2E；本阶段未新增浏览器视觉验收。
- 真实受控上传/解析 → CSV 预览 → 不持久化预检 → 幂等保存 → Chronos-2 两个条件场景 → 不可变制品读取通过。使用 720 点显式合成开发数据，同历史窗口下未来负荷保持 70% 与升至 95%。末端 P50 分别为 58.183475494384766 与 61.026729583740234；仅证明软件/模型调用链路，不证明工业适配性或因果关系。
