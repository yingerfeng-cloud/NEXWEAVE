# R1 现场演示后续收口报告 · 2026-09-14

## 范围

本轮根据 2026-09-13 R1 合成软件闭环演示中的真实操作反馈，修复流程连接不完整、成功回执误报、空态时机不准确和可信问答技术信息难以理解的问题。范围保持在 R1/M9.5 已有对象、API、Release/Evidence 门禁和前端路由，不进入 M10。

## 已完成

1. `SpacesPage` 将空间创建提交与后续目录刷新分离。服务端已提交时立即关闭表单、选择返回空间并防止重复提交；刷新失败显示为可重试的目录状态，不再显示“创建失败/网络失败”。成功后给出下一步资料入口。
2. `CompileCenter` 对 CompileJob、Schema、Source、Prompt 和 Model 资源使用独立结果投影。首轮请求结束前显示加载状态；资料目录请求失败时显示“暂时无法读取资料版本”，不会误导用户重新导入资料；成功编译后说明草稿、Wiki、审核和发布之间的关系。
3. Source 列表保留当前主体可见的 SourceVersion 摘要，Compile 直接显示 `PARSED/PARTIAL` 版本。既有密级过滤与公开字段投影继续生效。
4. Query 增加可选 `answer_reason` 只读解释码：`SUPPORTED_EVIDENCE`、`NO_MATCHING_KNOWLEDGE`、`EVIDENCE_UNAVAILABLE`、历史重新核验的两种结果。历史答案只在读取时推导，未修改存储答案；不会通过解释码泄露权限隐藏对象。
5. Ask 以业务语言呈现判定原因和下一步，并保留引用到安全原文预览的站内入口。治理步进器、编译轨迹和发布候选增加可读的下一步/门禁说明，Trace、ID 和完整 JSON 仍可展开查看。

- 新增 ADR-0037；无数据库迁移、无第三方依赖、无 Chronos-2/Provider/Domain Pack 变化。`answer_reason` 是读取解释，不是 Evidence、Observed Fact、ForecastArtifact、Release 或置信度。
