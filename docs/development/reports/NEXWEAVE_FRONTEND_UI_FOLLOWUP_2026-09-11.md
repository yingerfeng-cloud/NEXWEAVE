# NEXWEAVE 前端 UI 复核整改补充报告

日期：2026-09-11  
关联范围：M9-FE；桌面 Web；用户截图标注问题的针对性复核  
状态：整改完成，停止于 M9-FE

## 1. 本轮复核对象

本轮针对用户提供的发布中心、领域包、页面知识图谱和质量中心截图，回到真实 `web` 容器复现并测量 DOM 边界，确认不是旧缓存造成的假象。

## 2. 发现与修正

| 区域 | 问题 | 修正 |
| --- | --- | --- |
| 发布中心 / 质量中心 | 表单卡片与结果卡片为 0px 间距，边框连续，标题区域像被下一块内容压住。 | 为内容页相邻工作面建立统一 16px 垂直节奏，覆盖 `data-card`、`m7-grid`、编译工作流、Studio、Wiki 和主张布局。 |
| 领域包 | “可信制品”与“最近安装”视觉合并，错误安装记录缺少独立层级。 | 应用同一相邻卡片间距规则，保留失败状态及可靠任务说明，不改变回滚/禁用语义。 |
| 全部页面顶栏 | 顶栏显示“质量/发布/领域包”等当前页名，页面标题又显示“质量中心/发布中心/领域包”，产生重复。 | 顶栏第二行改为当前模块分组（工作台、知识建模、知识治理、智能使用、系统），页面主标题保留完整业务名称。 |
| 页面知识图谱 | 搜索、统计、出链说明和缩放控件只占左侧，宽屏右侧留下空白；说明块与其它控件高度不齐。 | 改为桌面分栏 Grid：搜索可伸展、统计分组、出链说明、标签和缩放控件均衡填充，并统一控件高度；窄屏保留两列折行。 |
