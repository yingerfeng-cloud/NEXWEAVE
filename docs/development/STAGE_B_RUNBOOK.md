# 阶段 B：自主绑定与条件场景操作

本地技术完成于 2026-09-09，依据 11D / ADR-0034。启动和恢复仍使用阶段 A 手册，代码版本为 `0.9.5-b1`。不进入 C/M10。

## 从现有页面开始

1. 登录并选择有权限的空间。进入 Wiki（也可从集成中心等已有运行态入口进入），切换“运行与未来 · 预览”。本地入口：`http://localhost:8080/wiki?view=living`。
2. 点击“新增运行数据绑定”。选择已上传且完成解析的 CSV、已发布时序 Schema/Profile，以及属于该 Schema/类型的已有知识对象。缺少资料时使用资料中心，缺少模型或对象时使用现有 Schema Studio/编译页面；本阶段不自动创建领域模型。
3. 选择资料版本、时间列、可选质量列，逐个映射信号列并填写原始单位。填写运行背景与数据来源性质；合成数据必须标记为合成，真实上传但未核验的数据保留未核验标记。
4. 预检成功后核对点数、起止时间再保存。修改任何绑定输入后需要重新预检。最终保存仍由服务器重新校验；重试保留幂等键，不重复创建绑定。
5. 在新绑定上设置历史步数、预测范围和显式未来工况路径，再运行预测。可取消或用冻结输入创建新运行，规则沿用阶段 A。
6. 完成两个场景后，在“同窗口场景比较”选择另一个成功结果，查看末端 P10/P50/P90 及其差值。仅同一绑定、相同历史观测、目标单位、模型 revision 和预测时间轴可比较。分位差不是差值的概率区间，条件预测不等于因果推断。

## 数据和失败处理

- CSV 为受控 SourceVersion 固定对象版本，≤2MB、≤32 列、32～20000 行；预览最多 5 行，每格最多 128 字符。预测历史最多 8192 点。
- 时间必须含时区且符合 Profile 的固定间隔；数值必须有限。配置质量列时要求 GOOD。拒绝空/重名列、残缺行及时间、质量和测点列重叠。
- 原始单位必须与已发布语义一致，不自动换算、插值或填补未来值。未来输入空白时不能提交。
- 源未解析、扫描未通过、已失效或已归档时不能新绑定/预测。失效以 R1 权威失效记录判断；历史制品仍保持不可变。
- 前置列表为空时检查空间、权限、已发布时序 Profile 和对象版本；列表支持继续加载资料。失败提示后可重载，模型离线时按阶段 A 手册恢复 worker。
- 若浏览器保留了过期会话，重新登录并刷新页面。部署后的前端资产已核对包含阶段 B 功能。

## 复验与边界

在已有 M9.5 合成开发环境中，使用项目 `.venv` 运行 `scripts/verify_stage_b.py` 可追加合成 CSV/绑定并执行两次真实 Chronos-2 推理；`scripts/verify_stage_b_invalidated.py` 仅失效并归档它新建的合成测试资料，保留主演示资料。两者会写本地运行记录，不是只读命令。

本阶段不产生 Evidence、Observed Fact 或 Release。已有知识回接、自由文本 Ask、完整动态图投影、签名时序 Pack、工业数据评测及生产部署仍按后续授权处理；不能把当前合成 P-101 结果当作现场故障概率或控制建议。
