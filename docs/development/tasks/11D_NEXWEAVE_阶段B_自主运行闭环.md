# 阶段 B：用户自主完成运行知识闭环

用户明确下发：2026-09-09“请进入阶段B，注意节约额度”。依据 ADR-0034；沿用阶段 A 稳定基线，停止边界为 B，不进入 C 或 M10。

目标：已有合规上传资料、已发布时序 Schema 和已编译知识对象的用户，无需开发脚本即可在现有运行态页面选择 CSV、对象、Schema/Profile，配置时间列/测点列/原始单位/质量列，预检并保存不可变绑定，运行显式条件场景，查看结果并比较同一历史窗口的两个预测。

范围：复用资料中心上传、Schema Studio 审批和既有模型 Gateway；补受控 CSV 有界预览与绑定预检契约、可视化绑定流程、历史步数/输入空值校验、场景比较与来源提示。绑定最终提交在后端重新校验，不信任前端预检。单位不自动转换、缺失不自动填充；预检不调用模型。

验收：真实 CSV 经受控上传/解析→预览→绑定验证→保存→Chronos 预测→制品查询；错误单位、错误列、质量码、非规则时间、越权和重复提交可控；前端有空态、加载、失败重试、预检失效和比较不可兼容提示；现有 A 取消/恢复及 R1 Evidence/Release 边界保留。

不含：从零生成领域 Schema/知识对象、Schema 新审批机制、签名 Pack 发布、现场连接器、工业 Benchmark、RCA 引用合成、自动控制或优化。没有前置资源时给出既有页面入口与具体说明；禁止提供伪造默认设备/信号。
