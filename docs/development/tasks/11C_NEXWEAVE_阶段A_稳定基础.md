# 阶段 A：R1 + M9.5 稳定基础

用户正式下发：2026-09-08“请开始阶段A：稳定基础”。依据 ADR-0033；保留 11B 与所有 R1 不变边界。

范围：统一本地启动/版本；修复请求追踪串号；持久化预测投递、Temporal 对账、活动崩溃恢复；取消与保留历史的新运行；健康状态和必要操作入口；重跑 R1 完整软件闭环。

验收：
- 同一启动入口可以恢复既有基础服务和可选预测 worker，重复启动不重复 worker；worker 离线状态可见。
- API 已受理任务在投递故障后自动恢复，成功制品只提交一次；worker 被杀后恢复活动。
- 取消后晚到活动不能发布制品；失败/取消重跑创建新任务并关联旧任务、冻结输入，不修改终态。
- 每次 HTTP 请求保持自身 W3C trace，覆盖大文件上传后的 keep-alive 和并发请求。
- 隔离测试空间实际完成 Source→Compile→Review→Release→Query 和发布指针回滚；测试身份与合成材料保持显式标记。
- 新迁移升级/降级、相关单元/契约/回归、前端类型/测试/构建和真实运行证据通过。

非目标：绑定向导、工业 Benchmark、真实专家阈值、已发布 RCA 引用合成、新模型、SCADA/控制/优化、阶段 B 或 M10。
