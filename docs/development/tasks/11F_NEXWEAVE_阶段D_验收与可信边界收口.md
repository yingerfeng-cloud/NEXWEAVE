# 阶段 D：验收与可信边界收口

用户明确下发 D 并选择“验收与可信边界收口”；遵循节约额度要求，复用 A—C 制品与合成验证环境，停止在 D，不进入 M10。

依据 ADR-0036 修复已记录的固定 Release Query/Graph 问题：新问答仅合成有当前有效引用的冻结主张；历史答案读取/重放重新过滤权限与来源；重放键不得跨问题或 Release 复用。关系图只读取发布快照，校验起点/终点成员及可见性，关系证据属于所选发布；有界遍历不得静默把截断当完整结果。

真实浏览器验证现有运行态入口、绑定预检、场景结果比较、固定发布知识回接及原文定位。沿用已完成时序推理，必要时仅创建测试绑定，不重新大批量模型推理。针对变化做单元、真实数据库/HTTP 与浏览器验证，修复发现的问题并记录未覆盖边界。

无工业数据准入、工业模型评测、专家阈值批准、新 Provider、新优化/控制能力或生产高可用扩展。无新业务写入权威；历史发布、答案和制品不原地改写。
