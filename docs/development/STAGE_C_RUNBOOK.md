# 阶段 C：已发布知识回接

依据 11E / ADR-0035，阶段 C 的目标是为现有预测查找可核验的发布知识背景。入口仍为 Wiki、Graph、Ask 等页面的“运行与未来 · 预览”，不新增模型中心。

## 操作

1. 登录并选择知识空间、运行数据绑定，以及一个已有成功预测。无需重新运行 Chronos-2。
2. 在预测结果下方找到“查找已发布知识依据”，显式选择同空间固定发布版本；该选择不会随发布指针切换。
3. 输入要核实的现象、规程或历史案例关键词，点击“检索已发布依据”。优先使用资料原语言中的关键词；当前检索沿用已有 R1 Gateway/检索能力，不承诺跨语言理解或自动诊断。
4. 查看支持材料和“查看原文定位”。展开引用来源可核对主张、证据、SourceAnchor、发布版本及其哈希、预测哈希和查询记录。
5. 修改问题或知识版本后，旧依据立即清空，重新检索后显示新结果。核验时间表示本次查询时有效，不保证页面停留期间来源永远有效；需要最新状态时重新检索。

没有可用发布版本时，先经现有知识审核/发布流程准备资料。没有有效匹配时明确返回证据不足，不能据此认定没有风险。已弃用版本带历史提示，不自动替换；源失效或归档、证据/Anchor 不再有效、当前权限不足时，相关材料不返回。

## 本地合成示例

P-101 演示空间中，阶段 B 的既有 Chronos 制品已与阶段 C 新建的合成参考知识跑通回接。该材料中的 Pump A 是明确标记的虚构参考，不能用于实际设备检修。正常示例 Release、推荐查询及对应制品见 `docs/development/reports/阶段C_运行证据.json`；可用关键词为 `lubrication vibration`。另有用于来源失效验证的测试发布版本，返回证据不足是预期行为。

## 复验与运行

统一启动/恢复沿用阶段 A 手册。API 与可选预测 worker 使用同一代码版本 `0.9.5-c1`；升级后需重启本地 worker，否则严格版本匹配会报告不可用。

使用项目 `.venv` 运行 `scripts/verify_stage_c.py`，会复用已有阶段 B 制品，并在缺少本地检查点时新建合成资料、Schema、编译、测试审核角色和发布记录；复用 M6/M7 验证门禁。`scripts/verify_stage_c_invalidated.py` 创建独立测试参考并将其失效，保留正常示例；失效脚本一次性执行，不应把已经失效的检查点当作新的正向起点。发布验证后恢复原先存在的 stable 指针，不删除历史记录。

## 边界

本次回接是读时组合，不改写历史 ForecastArtifact。旧产物里“未选择 Release”仍是当时的真实记录；新卡片是本次检索结果。Forecast/Potential Event/Hypothesis 与 Released Knowledge 分层呈现，不能互相替代。引用相关材料不等于因果关系、设备适用性或专家诊断。

本阶段没有发布真实工业 RCA 规程/案例，没有工业 Benchmark、自动故障原因排序、完整自由文本预测编排或正式动态图遍历升级；不进入 M10。
