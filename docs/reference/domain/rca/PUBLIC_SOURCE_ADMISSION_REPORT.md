## 1. 准入方法

本次复核同时检查了文件完整性、PDF 可打开性、逐页文本提取、关键结论页版面和第三方来源标识。文件的字节数、页数和 SHA-256 与 accession manifest 一致；610 页均能提取文本。关键 probable cause/conclusions 页面逐份渲染目检，未发现裁切、乱码或不可读正文。

`excludedVisualPages` 表示该页存在第三方来源标识、第三方图片/地图，或属于以图像为主且不适合自动取证的附录页。它排除的是对应视觉元素，不是自动排除同页 NTSB 自有正文。若证据依赖被排除的视觉元素，必须拒绝自动引用并转人工权利复核。

## 3. 首批代表性案例

首批端到端技术试点选择 4 份相互独立的报告：

1. `NTSB-MIR-22-06`：大修装配/扭矩—润滑丧失—连杆破坏；
2. `NTSB-AAR-18-01`：制造异常—低周疲劳—非包容失效；
3. `NTSB-PIR-22-02`：硬点/涂层/阴极保护—氢致开裂—管道破裂；
4. `NTSB-RIR-24-05`：轴承热失效—路旁检测—报警与应急决策。

其余 5 份保留为扩展集。该选择覆盖海事、航空、管道和铁路，并避免将多个相似紧固件案例重复计算为独立根因覆盖。

## 4. 强制边界

- Raw PDF 保存在 git 忽略目录；平台 SourceVersion 记录原始 checksum，派生段落不得覆盖 Raw。
- 自动编译产物只允许处于 Draft/Review，不因本报告直接获得 Release 资格。
- 本地结构化编译器是确定性技术验证器，不是外部 LLM，也不是 RCA 专家。
- 引用不得只指向封面、目录、低文本页或被排除的视觉元素。
- 任何真实 Release 仍需具备签署权限的领域专家审阅；阈值仍需产品/RCA 专家批准。
- 公开资料试点结论不得外推为客户现场、特定设备群或 GridCrew 联合试点结论。
