# ADR-006: Artifact 与 Evidence 分离

- 状态：Accepted
- 日期：2026-07-25
- 关联：PRD V2.2 第 11、12、13 章；开发计划 V2.2 第 2、8 章

## 背景

GridCrew 需要正式成果沉淀，也需要审计、复现和问题回放证据。

## 决策

Artifact 与 Evidence 是分离的领域对象。

## 理由

正式交付物和证据链生命周期、访问权限、保留策略和使用场景不同。

## 影响

任务完成后应发布 Artifact，并保存支撑该成果的 Evidence 引用、校验值和摘要。

## 替代方案

将证据作为成果附件或聊天消息。

## 后续约束

不得以聊天记录替代 Artifact 或 Evidence。
