# ADR-008: 平台资产全面版本化

- 状态：Accepted
- 日期：2026-07-25
- 关联：PRD V2.2 第 5、6、10、11、13 章；开发计划 V2.2 第 2、8 章

## 背景

数字员工、Skill、Workflow、Tool、Connector、成果和评测都需要可追溯、可回放和可审计。

## 决策

平台核心资产全面版本化。

## 理由

版本化可以支撑发布、回滚、复现、审计、评测和客户交付。

## 影响

M0/M1 需要定义版本字段、引用关系和不可覆盖策略。

## 替代方案

原地覆盖配置和成果。

## 后续约束

正式成果不可原地覆盖，只能创建新版本。
