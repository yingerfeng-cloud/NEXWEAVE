# ADR-001: Temporal 作为唯一正式执行内核

- 状态：Accepted
- 日期：2026-07-25
- 关联：PRD V2.2 第 1、9、16 章；开发计划 V2.2 第 1、2、9 章

## 背景

PRD 和开发计划明确要求 R1 起真实运行长任务、等待人工、审批、定时任务、失败恢复和跨系统调用。

## 决策

Temporal 是 GridCrew 正式任务、审批、定时、长任务、跨系统执行和补偿的唯一可靠执行内核。

## 理由

该决策避免首期使用数据库状态机或临时队列形成未来需废弃的任务内核。

## 影响

M0 必须建立 Temporal Server、Worker 边界、最小真实 Workflow/Activity、重试和可观测门禁。

## 替代方案

数据库状态机、消息队列任务流、Agent 图状态机。

## 后续约束

PostgreSQL、LangGraph、消息队列不得成为第二套任务生命周期权威。
