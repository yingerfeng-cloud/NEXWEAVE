# ADR-003: 所有模型调用经过 Model Gateway

- 状态：Accepted
- 日期：2026-07-25
- 关联：PRD V2.2 第 9、10、15 章；开发计划 V2.2 第 2、9 章

## 背景

GridCrew 不绑定单一模型或供应商，生产环境需要公网模型与私有模型切换能力。

## 决策

所有模型调用必须通过 Model Gateway。

## 理由

统一治理模型策略、供应商隔离、审计、脱敏、成本和安全。

## 影响

领域代码和 Agent Runtime 不得直接绑定模型厂商 SDK。

## 替代方案

各模块直接接入模型 SDK。

## 后续约束

M0 需冻结 Model Gateway 契约和配置边界，但不必实现完整模型能力。
