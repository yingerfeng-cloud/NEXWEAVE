# ADR-005: 多租户从第一天进入领域模型

- 状态：Accepted
- 日期：2026-07-25
- 关联：PRD V2.2 第 12、15、16 章；开发计划 V2.2 第 1、2 章

## 背景

GridCrew 面向企业私有化、多租户运营和组织级治理。

## 决策

所有核心领域对象从第一天考虑 `tenant_id`、组织、空间和数据范围。

## 理由

避免后续补租户字段造成数据迁移、权限重构和审计断裂。

## 影响

M0/M1 必须建立租户字段、测试和访问控制约束。

## 替代方案

先单租户实现，后续再改造。

## 后续约束

查询、命令、事件、对象存储和日志均需考虑租户范围。
