# GridCrew Reference Archive

本目录保存 2026-08-23 从相邻 GridCrew 项目复制的治理参考快照，目的仅是对齐：

- Temporal 执行权威与数据库业务投影；
- Model Gateway、Tool Gateway、Connector 边界；
- 多租户、服务身份、权限与审计；
- Artifact/Evidence 分离；
- 版本化 Skill、Connector 和 EmployeeRelease；
- 统一事件 Envelope、Outbox、幂等和 correlation ID。

这些文件不得覆盖 NEXWEAVE 的独立产品定位。若 GridCrew 后续基线变化，必须通过联合契约评审和 ADR 更新，不得直接同步覆盖本快照。
