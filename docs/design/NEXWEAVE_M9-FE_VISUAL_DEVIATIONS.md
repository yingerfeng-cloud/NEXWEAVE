# NEXWEAVE M9-FE 视觉偏离清单

> 日期：2026-09-01  
> 对照：`NEXWEAVE_高保真交互原型_V1.0.html`  
> 原则：原型提供信息架构与视觉方向；真实契约、权限、数据和可访问性优先。

| 原型表现 | M9-FE 实现 | 偏离理由 | 验收结论 |
|---|---|---|---|
| 固定演示 KPI、资料、任务、Release 与连接状态 | 仅展示真实 API 返回的指标、列表、空态或错误 | 防止 Mock、固定 JSON 和演示成功被冒充为产品能力 | 接受；符合真实性约束 |
| Global Search 呈现为全局知识搜索 | `Ctrl/Cmd+K` 打开真实可达路由的快速导航 | 当前没有独立全局知识搜索契约；知识查询由 Ask NEXWEAVE 的固定 Release API 承担 | 接受；不制造不可达交互 |
| 约 250px 固定左侧栏 | 760px 以下改为顶部品牌/空间区和横向可滚动导航 | 保证 390×844 下内容可用且无页面横向溢出 | 接受；响应式优先 |
| 部分 10—11px 文案和紧凑控件 | 信息文字至少约 12px，常用控件约 36px，焦点环 2px | 满足中文可读性、触控和键盘焦点基线 | 接受；可访问性优先 |
| 单页隐藏/显示模拟页面切换 | 保留真实 URL、History、刷新恢复和深链接 | 路由是已验收的可恢复状态，不可为视觉对齐退化 | 接受；功能语义优先 |
| 原型静态侧栏页序和演示入口 | 以当前 17 个真实受保护路由分组，并增加真实 `/tasks` 入口 | 任务中心已有真实 API 实现，原先仅缺路由入口；未新增业务能力 | 接受；信息架构与真实能力对齐 |
| 原型用演示正常态覆盖多数页面 | 实现保留空、加载、错误、权限拒绝、冲突与安全失败表达 | 错误和权限结果不能被视觉层隐藏或改成成功 | 接受；真实状态优先 |
| 图谱使用自由动态色 | Wiki 图谱使用受控 8 色可视化 token | 避免任意颜色破坏主题和语义一致性，同时保持节点可区分 | 接受；设计系统一致性优先 |
| 原型可能依赖展示性字体/图形效果 | 使用系统字体、CSS 与受控内联图形，不请求远程字体、图片或 CDN | 保持离线内网可部署，不新增依赖和许可证面 | 接受；部署与供应链优先 |

本清单不改变 M1—M9 API、领域对象、权限、Evidence、Release、Workflow 或审计语义，也不授权 M10。
