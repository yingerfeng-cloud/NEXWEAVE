# Equipment RCA Living declarations — M9.5 development overlay

`temporal-declarations.json` provides four signals and one forecast profile as a declarative,
space-local overlay on the existing core and Equipment RCA declarations. The seed script
uses the normal Schema validate/publish APIs with a separate technical publisher identity.
It does not modify the signed Equipment RCA Pack 1.0.0 manifest, invent an expert approval,
or claim that this overlay is a newly signed/installed Domain Pack release.

Temperature is the target, vibration and lubrication pressure are past covariates, and
unit load is a known-future input only when supplied by the user as an explicit assumption.
Operating context is captured in the binding. Numeric units must match exactly; automatic
unit conversion, categorical covariates, subtype-wide binding and live Historian polling
are outside this first slice.

P-101 data are generated by `scripts/verify_m95.py`, labelled SYNTHETIC, uploaded through
Source ingestion, scanned and parsed. The demonstration attention threshold (60 degC) is
not an industrial alarm threshold, a fault probability, or a released operating procedure.
