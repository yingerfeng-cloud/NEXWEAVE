## 原型功能范围

原型包含 16 个一级页面：

- 总览
- 知识空间
- 资料中心
- 编译中心
- Wiki
- Schema Studio
- 主张与证据
- 关系图谱
- 冲突中心
- 审核中心
- 质量中心
- 发布管理
- Ask NEXWEAVE
- 领域知识包
- 集成中心
- 系统管理

## 可交互操作

- 导入资料并生成新记录
- 创建知识空间
- 启动知识编译任务
- 切换 Wiki 页面
- 新增 Schema 实体和关系
- 选择图谱节点
- 解决知识冲突
- 批准、驳回或要求补充审核资料
- 运行质量评估
- 创建发布候选
- 进行带引用的可信问答
- 安装领域知识包
- 测试集成连接
- 保存系统设置
