轴承润滑不足

Root Cause · CAUSE-BEARING-LUBRICATION-001 · 适用于离心泵
轴承润滑不足会造成油膜承载能力下降与摩擦增加，可能进一步导致轴承温度升高、异常磨损和振动升高。

故障机理

[[润滑油压力下降]] 或油品性能劣化会削弱轴承表面的油膜形成能力，导致摩擦热增加。当润滑状态持续恶化时，可能形成 [[轴承异常磨损]]，并表现为 [[轴承温度升高]] 与 [[径向振动升高]]。

可能上游原因

  • [[润滑油过滤器堵塞]]
  • [[润滑油泵性能下降]]
  • [[润滑油路局部堵塞]]
  • 润滑油牌号或黏度不符合要求

验证方法

  1. 核对润滑油压力的趋势与报警时间；
  2. 检查滤芯压差和污染情况；
  3. 开展油样颗粒度、黏度及金属磨粒分析；
  4. 结合振动频谱和轴承温度趋势排除不对中等原因。

适用边界

仅凭“振动升高 + 温度升高”不能直接确认润滑不足，应结合油压、油质、检修记录和拆检证据进一步验证。
